# Latin Modern Roman

The four unmodified `lmroman10-*.otf` files supply the regular, bold, italic and bold-italic
faces used by the manuscript. Latin Modern is based on Donald Knuth's Computer Modern fonts.
This bundle was copied from the Latin Modern 2.005 distribution installed with MiKTeX.

[README](README-Latin-Modern.TXT) and [full distribution manifest](MANIFEST-Latin-Modern.TXT).
The local bundle is a subset of the font distribution; the upstream manifest describes the whole
distribution. Font names and bytes are unchanged.

[Upstream Latin Modern project](https://www.gust.org.pl/projects/e-foundry/latin-modern/).
KaTeX supplies the manuscript's mathematical glyphs through its separately installed font package.
